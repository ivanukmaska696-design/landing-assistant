# Лендинг-асистент MI.IVANUK

Безкоштовний інструмент для тих, хто хоче зібрати свій лендинг разом із Claude.

**Відкрити:** https://ivanukmaska696-design.github.io/landing-assistant/

## Що всередині

- **Конструктор брифу.** Оберіть шаблон ніші або заповніть форму з нуля, і за секунди отримаєте готовий промпт для Claude. Там, де даних бракує, промпт просить залишити помітні місця, а не вигадувати.
- **Як ми зробили сайт MI.IVANUK.** Сім етапів і реальні уроки: шрифти з кирилицею, мобільна версія, перевірка цифр, запуск.
- **Чекліст перед запуском:** 14 пунктів про чесність, телефон і технічні деталі.
- **Часті питання:** хостинг, домен, Meta Pixel, як просити правки.

## Як користуватися

1. Відкрийте сторінку й заповніть бриф.
2. Скопіюйте промпт і вставте його в новий чат з Claude.
3. Додайте до повідомлення свої фото та скріни кейсів.
4. Перевірте готовий сайт на телефоні й звірте всі цифри.

Бриф зберігається лише у вашому браузері, сторінка нічого нікуди не надсилає.
